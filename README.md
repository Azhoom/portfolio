<h1 align="center">Adham Hamed — Live Streaming Technical Director Portfolio</h1>

Portfolio website for **Adham Hamed**, Live Streaming Technical Director & Operator with nearly 6 years of experience in mid to large-scale esports and live event broadcasts across regional and international platforms (Esports World Cup, PUBG Mobile National Championship, Honor of Kings World Finals, Intel Arabian Cup).

Built with [Remix](https://remix.run/), [Three.js](https://threejs.org/), and [Framer Motion](https://www.framer.com/motion/).

## Install & run

Make sure you have Node.js installed. Install dependencies with:

```bash
npm install
```

Once installed, start the local development server:

```bash
npm run dev
```

To run the Storybook components library:

```bash
npm run dev:storybook
```

## Production Build & Deployment

Build for Cloudflare Pages or deploy:

```bash
npm run build
npm run deploy
```
